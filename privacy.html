Политика обработки данных

1. Какие данные мы собираем

Сервис LVK Service не собирает и не хранит персональные данные пользователей на собственных серверах. Взаимодействие происходит через платформу Telegram, которая предоставляет базовую информацию профиля (имя, username, аватар) в соответствии с собственной политикой конфиденциальности.

2. Данные, получаемые от Telegram

При использовании веб-приложения Telegram Web App Сервис может получать:

  • Имя пользователя (first_name)
  • Username (если установлен)
  • Языковой код интерфейса

Эти данные используются исключительно для отображения в интерфейсе и не сохраняются на постоянной основе.

3. Файлы cookie и локальное хранилище

Сервис не использует файлы cookie для отслеживания пользователей. Локальное хранилище браузера может использоваться для временного кэширования данных сессии, что обеспечивает корректную работу интерфейса. Эти данные не передаются третьим лицам.

4. Передача данных третьим лицам

LVK Service не продаёт, не передаёт и не раскрывает данные пользователей третьим лицам. Единственным исключением являются случаи, предусмотренные законодательством, либо прямой запрос пользователя на передачу данных (например, через сервис гаранта).

5. Безопасность

Сервис работает через защищённое соединение Telegram и не обрабатывает платёжные данные напрямую. Все финансовые операции проводятся через сторонние сервисы (кошельки USDT) по договорённости сторон. Сервис рекомендует пользователям соблюдать меры предосторожности при совершении сделок.

6. Изменения в политике

Мы оставляем за собой право обновлять данную политику конфиденциальности. Актуальная версия всегда доступна на этой странице. Продолжая использование Сервиса, вы соглашаетесь с внесёнными изменениями.

7. Контакты

По всем вопросам, связанным с обработкой данных, вы можете обратиться в поддержку Сервиса через соответствующий раздел на главной странице или напрямую через Telegram-бот.
